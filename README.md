# Sira Gebeya

Sira Gebeya is a responsive job marketplace platform designed to connect job seekers with employers in one easy-to-use system. It helps solve the common problem of fragmented hiring by bringing job discovery, profile management, job posting, and application tracking into a single, organized experience.

## Live Demo

[click here and View the live site ](https://resplendent-starship-9acec3.netlify.app/)

## Project Overview

This project was built as a modern web interface for the hiring process. Instead of forcing users to move between separate tools for searching jobs, managing candidates, or following up on applications, Sira Gebeya centralizes the process into one platform.

The app is designed for two main users:

- Job seekers who want to explore opportunities, manage their profile, and apply for roles more efficiently.
- Employers and recruiters who need a better way to publish jobs, review candidates, and organize the hiring workflow.

## Problem It Solves

Job searching and hiring are often slow, confusing, and disconnected. Job seekers may struggle to find relevant opportunities, while employers often spend too much time managing listings and candidates across multiple channels.

Sira Gebeya addresses that gap by creating one platform where both sides of the hiring process can connect faster, communicate more clearly, and work in a more structured way.

## What The App Does

- Lets job seekers browse opportunities and manage their profile information.
- Helps employers create and organize job listings.
- Supports candidate tracking and hiring-related workflows.
- Includes pages for login, registration, job management, interview scheduling, chatbot assistance, and user profiles.
- Provides a clean, responsive interface for a smoother user experience on desktop and mobile devices.

## Key Features

- Responsive landing page with a modern visual design.
- Job seeker dashboard with profile details, saved jobs, recommendations, and notifications.
- Employer-focused job management pages for posting and organizing roles.
- Interview scheduling and candidate workflow pages.
- Chatbot assistant for guiding users through common questions and actions.
- Subscription plans for different employer needs.

## Project Structure

- `home/` - main homepage and landing content
- `job seeker/` - job seeker pages such as profile, application, and company views
- `company/` - employer and admin pages such as job management, chatbot, messaging, and interview scheduling
- `chat.html` - chat interface
- `reg.html` - registration page
- `logincap.html` - login page

## How To Run Locally

This is a static front-end project, so no build step is required.

1. Clone the repository.
2. Open `home/homepage.html` in your browser, or use VS Code Live Server.
3. Navigate through the linked pages to explore the full experience.
